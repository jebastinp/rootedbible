# Post-launch roadmap

These phases are conditional on the launch checklist; no date or delivery commitment is implied.

| Phase | Outcome | Evidence / exit |
|---|---|---|
| Internal 0.1 | Foundations, rights controls, synthetic validation | Owner reviews artifacts; architecture confirmed |
| Internal 0.5 | Approved dataset, reader, chapter progress, one plan, settings | Automated + device acceptance matrix |
| Beta 0.9 | Test real reading with approved content and representative users | No P0, critical P1 resolved; content QA accepted |
| Public 1.0 | Trustworthy core loop | Exact build, rights, security, privacy, store and support approved |
| First 24 hours | Stabilize | Launch/chapter/progress failures and support triaged; rollback ready |
| First 7 days | Remove first-session friction | Consented feedback and justified metrics; prioritize one biggest issue |
| First 30 days | Product review | Reading comfort, plan usefulness, progress accuracy, language demand and return behavior |
| 1.1 | Reliability and accessibility | Verified fixes and migration notes |
| Later | Consider search/bookmarks/notes/additional editions | Value, rights, cost, privacy and performance review |

Beta cohorts: new and regular readers; approved Tamil/English/other-language readers; screen-reader and large-text users; low-memory devices. Ask what confused them, felt slow, seemed inaccurate or unnecessary. Content concerns escalate to content QA/rights owner before changing text.

Support categories: Bible content, translation, progress, plan, account (if retained), reminder, crash, performance, privacy and licensing. Owner must provide an actual contact and escalation roster. Proposed two-business-day general triage target remains unpublished until resourced; P0/content-rights incidents need immediate release-owner review.

Weekly management record: completed deliverables with evidence, blockers, changed decisions, largest risk, scope removed, next week's top outcome. Task status changes require results, not code existence. Retention metrics are only reported if consented collection and longitudinal measurement have been explicitly approved.
